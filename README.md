# Modern Weather Forecast App

A beautiful and modern weather application that provides real-time weather information for any city worldwide. Built with HTML, CSS, and JavaScript, using the OpenWeatherMap API.

## Features

- 🌡️ Real-time weather data
- 🎨 Modern and responsive design
- 🌍 Search weather by city name
- 💨 Wind speed information
- 💧 Humidity details
- 🎯 Dynamic weather icons
- ⚡ Fast and lightweight

## Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API

## Setup

1. Clone this repository
2. Replace the API key in `index.html` with your own OpenWeatherMap API key
3. Open `index.html` in your browser
